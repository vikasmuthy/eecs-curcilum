# EECS Curriculum — Master Index

Relearning EE and CS from the ground up, MIT-course-numbering style. EE phases (0–4) are done first; CS (Phase 5) fills in afterward. Math/physics prerequisites are pulled forward just-in-time whenever a later course needs them, rather than being strictly finished up front.

Status values: `not started` / `in progress` / `done`.

## Layout

Each course lives in `<course-number>-<short-name>/`:
- `README.md` — description, prerequisites, topic list, per-topic status
- `notes/` — one markdown file per lecture/topic, filled in as we go, plus a `00-glossary.md`

## Conventions & quality bar

Before generating or reviewing any note, see:
- [CONVENTIONS.md](CONVENTIONS.md) — zero-assumed-knowledge rule, file naming, notation, cross-linking
- [NOTE_TEMPLATE.md](NOTE_TEMPLATE.md) — the required section structure for every note
- [RUBRIC.md](RUBRIC.md) — the checklist a note must pass before its status flips to `done`
