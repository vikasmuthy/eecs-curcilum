# Drill Bank — Lumped Circuit Abstraction, KVL/KCL

100 worded problems for 6.002 Topic 01. No solutions, no hints, no worked steps — that's deliberate. Work each one cold.

**Self-verification method for this topic (not an answer key — a way to catch your own mistakes):** every problem below can be checked the same two ways the note's own worked examples use. (1) **KVL closure** — walk your solved loop/path of node potentials back to your starting node; if it doesn't return to the same value (or to your reference's $0\text{ V}$), you have a sign or bookkeeping error somewhere. (2) **KCL balance** — at every node, add up all currents you computed flowing in and all flowing out; they must match exactly. If either check fails, the numeric answer is wrong — full stop, go find the error rather than shrug at a "close enough."

Scope note: every problem here is solvable using only KVL, KCL, Ohm's law ($v=iR$), and independent voltage/current sources — nothing from later topics (no dependent sources, no capacitors/inductors, no node/mesh systematic algorithm) is needed or expected.

## Batch 1 (1–25) — Abstract resistor networks

1. A single loop has a $15\ \text{V}$ source in series with $R_1=220\ \Omega$ and $R_2=330\ \Omega$. Find the loop current and the voltage across each resistor.
2. A single loop has a $6\ \text{V}$ source in series with three resistors: $47\ \Omega$, $68\ \Omega$, and $100\ \Omega$. Find the current and the voltage across the largest resistor.
3. Node $A$ connects to ground through two parallel resistors, $R_1=2\ \text{k}\Omega$ and $R_2=6\ \text{k}\Omega$, and an ideal current source injects $9\ \text{mA}$ into node $A$. Find $V_A$ and both branch currents.
4. Node $A$ connects to ground through three parallel resistors: $1\ \text{k}\Omega$, $3\ \text{k}\Omega$, and $6\ \text{k}\Omega$. A current source injects $12\ \text{mA}$ into $A$. Find $V_A$.
5. A loop has two sources in series aiding each other ($8\ \text{V}$ and $4\ \text{V}$, both driving current the same direction) and a single resistor $R=60\ \Omega$. Find the loop current.
6. A loop has two sources in series opposing each other (a $10\ \text{V}$ source and a $3\ \text{V}$ source wired so their polarities fight) and a resistor $R=140\ \Omega$. Find the loop current and its actual physical direction.
7. Node $A$ has a $5\ \text{mA}$ current source injecting in, and two resistors to ground, $R_1=500\ \Omega$ and $R_2=1.5\ \text{k}\Omega$, in parallel. Find $V_A$ and the current through $R_1$.
8. A series loop has a $20\ \text{V}$ source and four equal resistors of $50\ \Omega$ each. Find the loop current and the voltage across any two of them combined.
9. Two resistors $R_1=10\ \Omega$ and $R_2=40\ \Omega$ are in series with a $25\ \text{V}$ source. A node $B$ sits between them. Find $V_B$ if the node adjacent to the source's $+$ terminal is the reference.
10. A $3\ \text{mA}$ current source feeds node $A$, which connects to ground through a single resistor $R=8\ \text{k}\Omega$. A second, separate $2\ \text{mA}$ source also feeds the same node. Find $V_A$.
11. A loop has a $9\ \text{V}$ source and two resistors in series, $R_1=150\ \Omega$ and $R_2$ unknown; the current is measured at $30\ \text{mA}$. Find $R_2$.
12. Node $A$ connects to ground through $R_1=1\ \text{k}\Omega$, and separately a $4\ \text{V}$ ideal voltage source connects node $A$ directly to ground (so $V_A$ is fixed). Find the current through $R_1$.
13. A loop has a $12\ \text{V}$ source, a $220\ \Omega$ resistor, and a $470\ \Omega$ resistor in series. A node between the two resistors is labeled $M$. Find $V_M$ relative to the source's negative terminal (ground).
14. Node $A$ has two current sources: one injecting $7\ \text{mA}$, one extracting $2\ \text{mA}$, and a single resistor $R=4\ \text{k}\Omega$ to ground. Find $V_A$.
15. A loop has one source of unknown value $V_s$, in series with $R_1=25\ \Omega$ and $R_2=75\ \Omega$; the measured current is $0.2\ \text{A}$. Find $V_s$.
16. Node $A$ connects to ground via $R_1=3\ \text{k}\Omega$ and also, through a separate branch, via $R_2=9\ \text{k}\Omega$ in parallel; a $6\ \text{mA}$ current source feeds $A$. Find the current through $R_2$ specifically (not just $V_A$).
17. A single loop has three resistors in series ($10\ \Omega$, $20\ \Omega$, $30\ \Omega$) and a $18\ \text{V}$ source. Find the voltage across the $20\ \Omega$ resistor only.
18. Node $A$ connects to ground through a single resistor $R=2.2\ \text{k}\Omega$. Two current sources feed $A$: one injecting $4\ \text{mA}$, one injecting $6\ \text{mA}$. Find $V_A$.
19. A loop has a $30\ \text{V}$ source and two resistors in series whose ratio is $R_1:R_2 = 1:4$. If the voltage across $R_2$ is measured at $24\ \text{V}$, find both resistor values (you'll need the total loop equation too).
20. Node $A$ connects to ground through $R_1=5\ \text{k}\Omega$ in parallel with $R_2=20\ \text{k}\Omega$, driven by a current source of $6\ \text{mA}$ into $A$. Find the current through $R_1$ specifically.
21. A loop has a $7\ \text{V}$ source in series with a $10\ \Omega$ resistor, and the resulting current is found to be negative when assumed clockwise. State the actual physical current magnitude and direction, and explain what value of loop current you'd compute if the source's polarity were reversed instead.
22. Node $A$ has a $10\ \text{mA}$ current source feeding it and connects to ground through $R_1=1\ \text{k}\Omega$ in parallel with $R_2=1\ \text{k}\Omega$ (equal resistors). Find $V_A$ and confirm both branch currents are equal by symmetry.
23. A loop has a $22\ \text{V}$ source and two resistors in series, $R_1=R_2=110\ \Omega$ (equal). Find the current and confirm, using symmetry, why the voltage splits evenly.
24. Node $A$ connects to ground through three resistors in parallel: $2\ \text{k}\Omega$, $2\ \text{k}\Omega$, and $4\ \text{k}\Omega$. A $10\ \text{mA}$ source feeds $A$. Find $V_A$ and the current through the $4\ \text{k}\Omega$ resistor.
25. A series loop has a $16\ \text{V}$ source and two resistors; the current is $80\ \text{mA}$ and one resistor is known to be $R_1=100\ \Omega$. Find $R_2$ and the voltage across it.

## Batch 3 (51–75) — Sign-convention and pitfall traps

51. A loop current $i$ is assumed to flow clockwise through a $9\ \text{V}$ source and a $45\ \Omega$ resistor; solving KVL gives $i=-0.2\ \text{A}$. State, in words, what this negative sign actually means physically, and re-draw (in words) which direction the current truly flows.
52. At a node, four branch currents are all defined pointing *into* the node: $i_1=3\ \text{A}$, $i_2=-2\ \text{A}$, $i_3=1\ \text{A}$, and $i_4$ unknown. Using KCL, find $i_4$ and state its true physical direction.
53. Two ideal voltage sources are placed in the same loop, a $10\ \text{V}$ source and a $10\ \text{V}$ source, wired so their polarities directly oppose. A resistor $R=50\ \Omega$ completes the loop. Find the current, and explain in one sentence why this result makes physical sense.
54. A student writes KVL for a loop by summing "drops" for three elements but accidentally treats one resistor's drop as a rise (sign flipped). Given the correct three terms would be $-12,\ +i(20),\ +i(30)$, but the student wrote $-12,\ -i(20),\ +i(30)$, solve for $i$ under the student's (wrong) equation and explain what specific mistake in traversal direction would produce that particular sign error.
55. A node has a current source labeled "injects $4\ \text{A}$" but its arrow is actually drawn pointing away from the node in the circuit diagram. Explain how this affects the sign you should use for that term in the node's KCL sum, and solve for the node voltage given a single $R=2\ \Omega$ resistor to ground from that node.
56. Three nodes $A$, $B$, $C$ are wired in a single loop with a return to $A$. A student writes KCL at node $A$, KCL at node $B$, and then also KCL at node $C$, treating all three as independent equations. Explain why this is one equation too many, and what should be done instead.
57. A resistor $R_1=100\ \Omega$ connects nodes $A$ and $B$. A student writes "$V_{R_1} = 5\ \text{V}$" as if the resistor itself has an absolute potential. Rewrite this statement correctly in terms of $V_A$ and $V_B$, and, given $V_A=8\ \text{V}$ and the correct voltage difference of $5\ \text{V}$ in the $A\to B$ sense, find $V_B$.
58. Two branches connect the same two nodes $A$ and $C$: one is a resistor $R=20\ \Omega$, the other is claimed (incorrectly, by a confused student) to be "a wire with a $3\ \text{V}$ drop." Explain why an ideal wire cannot have a nonzero voltage drop, and what the student has actually mislabeled.
59. A loop is traversed counterclockwise instead of the textbook's usual clockwise convention. Given the same physical circuit as Problem 1 of Batch 1 (a $15\ \text{V}$ source with $R_1=220\ \Omega$, $R_2=330\ \Omega$), write the KVL equation in the counterclockwise sense and confirm you still get the same current magnitude.
60. A node has two resistors to ground, $R_1=1\ \text{k}\Omega$ and $R_2=3\ \text{k}\Omega$, and one current source of $8\ \text{mA}$ whose reference arrow a student drew pointing *out of* the node by mistake (meant to inject in). Solve for $V_A$ under the as-drawn (reversed) convention and explain what sign the true injected-current case would flip.
61. A single loop has a source and one resistor; a student solves and gets a current of exactly $0\ \text{A}$. Given the source is $12\ \text{V}$ and nonzero, explain what this result would imply about the resistor's value, and whether it's physically sensible for a resistor (as opposed to an open circuit).
62. At a node with five branches, a student's KCL sum accidentally omits one branch entirely. Given the correct equation is $i_1+i_2+i_3+i_4+i_5=0$ with $i_1=2,\ i_2=-1,\ i_3=3,\ i_4=-2,\ i_5=-2$ (all in amps), find what value of $i_5$ the student's incomplete equation (using only the first four terms) would incorrectly compute, and by how much it differs from the truth.
63. Explain, using a specific two-resistor series loop of your own design (pick your own values), why swapping a source's polarity in your diagram (but not re-solving anything else) simply negates the loop current's sign rather than requiring you to redo the whole problem.
64. A node's KCL equation is written correctly as $i_1+i_2=i_s$, but a student then separately writes Ohm's law using the wrong pair of nodes for one resistor's voltage (using ground-to-ground instead of $A$-to-ground). Explain what specifically is wrong with "ground-to-ground" as a voltage, and rewrite the correct Ohm's law expression for a resistor $R$ from node $A$ to ground.
65. A single loop's KVL equation sums to $+3\ \text{V}$ instead of $0$ after a student solves for the current and plugs back in. Explain what this nonzero residual means (compared to the KVL closure check described at the top of this drill bank) and what kind of error typically produces it.
66. Two current sources are drawn feeding the same node: one arrow points in, labeled $6\ \text{mA}$; the other arrow also points in, but is labeled $-6\ \text{mA}$. Explain whether these two branches are equivalent to each other, to no source at all, or to something else, and justify using the sign convention rules from this note.
67. A student mixes up "sum of drops = 0" and "sum of rises = 0" partway through one KVL equation, writing $-V_s$ for a resistor's drop instead of $+iR$. Given $V_s=10\ \text{V}$, $R=25\ \Omega$, one loop, find what current the student's incorrect equation produces, and compare it to the correct current.
68. A single node has one resistor to ground and one voltage source directly setting that same node's voltage (a floating-source-like situation, though simpler since one side is ground). Explain why you do not need to write a KCL equation to find that node's voltage, and what you use instead.
69. Explain, in one or two sentences, why a negative current is not itself evidence of an error, but a KCL sum that doesn't equal zero (after solving) always is.
70. A loop has a $20\ \text{V}$ source and two resistors; a student correctly finds the current, but then reports the voltage across one resistor with the wrong sign (reporting a rise where there should be a drop). Given $R=40\ \Omega$ and the correct current is $i=0.25\ \text{A}$ (drop in the traversal direction), state the correctly-signed voltage and explain what physically distinguishes a "rise" from a "drop" here.
71. Two identical resistors, $R_1=R_2=100\ \Omega$, are in parallel between node $A$ and ground, fed by a current source. A student claims "the equivalent resistance must be $200\ \Omega$ since there are two $100\ \Omega$ resistors." Using KCL and Ohm's law directly (not a shortcut formula), find the actual node voltage for a $10\ \text{mA}$ source and show what single equivalent resistance it corresponds to.
72. A student writing KCL at a node lists a resistor's current using $(V_B - V_A)/R$ when it should be $(V_A-V_B)/R$ for the "leaving node $A$" direction. Explain the effect of this sign flip on the final solved value of $V_A$ in a simple one-resistor-to-ground-plus-one-source circuit of your own choosing.
73. A loop contains two resistors and two sources of equal magnitude but a student cannot tell, from the problem wording alone, whether the sources aid or oppose. Given $V_1=6\ \text{V}$, $V_2=6\ \text{V}$, $R=100\ \Omega$, compute the current for both the aiding case and the opposing case, and explain how a KVL closure check would look different in each.
74. A student claims that because a wire has "zero resistance," it must also carry "zero current," confusing the wire's voltage-drop property with a claim about its current. Explain why this is wrong, using the flashlight circuit from Batch 2, Problem 26 as a concrete counterexample (the connecting wires there carry the full loop current with zero voltage drop).
75. Explain why picking a reference node (ground) is a free choice that never changes any physically measurable current or voltage difference, using the single-loop circuit from Batch 1, Problem 13 — recompute $V_M$ if instead the *source's positive terminal* (not the negative terminal) is chosen as the $0\ \text{V}$ reference, and confirm the voltage *difference* between the two choices of reference is unaffected.
