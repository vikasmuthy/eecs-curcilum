# Implementing FSMs with Flip-Flops + Combinational Logic

## Why this matters

Topic 12 finished with a pile of Boolean equations — next-state equations $Q_i^+=f_i(\dots)$ and output equations — but an equation is not yet a circuit. This note supplies the last step: a fixed, general architecture (**state register** + **next-state logic** + **output logic**, all sharing one clock) that turns *any* set of Topic 12 equations into an actual physical FSM, and proves that architecture is correct. The proof is not new work from scratch — it is a direct composition of results already proven in this course: Topic 10's edge-triggered flip-flop correctly implements $Q^+=D$ with zero race-through even when $D$ is derived from other flip-flops' outputs (exactly the claim proved for two chained flip-flops in Topic 10's Self-check Question 8), and this note generalizes that same zero-delay argument to $k$ simultaneously-updating flip-flops wired through Topic 12's combinational next-state logic. This closes a loop opened all the way back in Topic 08: an FSM is precisely a *designed*, *controlled* version of the feedback that made the SR latch bistable — the same "output wired back into the circuit's own input" topology, but with the raw wire replaced by clocked storage and purposeful combinational logic in between.

## Builds on

- [[6.004-computation-structures/notes/12-fsm-design-procedure]] — the next-state equations $Q_i^+=f_i(Q_{k-1},\dots,Q_0,x_1,\dots,x_m)$ and output equations produced by encoding and K-map minimization; this note wires those exact equations into a physical circuit, unmodified.
- [[6.004-computation-structures/notes/10-edge-triggered-d-flip-flop-master-slave]] — the D flip-flop's characteristic equation $Q^+=D$ and, critically, Self-check Question 8's proof that two edge-triggered flip-flops sharing a clock, with one's output feeding the other's input, update correctly with no race-through; this note generalizes that exact argument from 2 flip-flops to $k$.
- [[6.004-computation-structures/notes/08-bistability-sr-latch]] — the concept of feedback (a circuit's output wired back into its own input) and the self-consistency-equation framing used to analyze it; this note contrasts an FSM's *clocked*, combinational-logic-mediated feedback with the SR latch's *unclocked*, immediate feedback, explaining why the FSM architecture never faces the SR latch's "does a stable solution even exist" puzzle.

## Core definitions

- **State register** — a bank of $k$ edge-triggered D flip-flops (Topic 10), one per state variable $Q_{k-1},\dots,Q_0$, all sharing a single common clock signal; holds the FSM's current encoded state between clock edges.
- **Next-state logic** — a combinational circuit (built from Topics 03–07's gates) computing each flip-flop's $D$ input from Topic 12's next-state equations: $D_i = f_i(Q_{k-1},\dots,Q_0,x_1,\dots,x_m) = Q_i^+$ for every state variable $i$; its inputs are the state register's *current* outputs (fed back) together with the FSM's external input bits.
- **Output logic** — a second, separate combinational circuit computing the FSM's output bits from Topic 12's output equations; for a **Moore** FSM its inputs are the state register's outputs *only* (no external input wire, matching $\lambda:S\to O$'s signature); for a **Mealy** FSM its inputs are the state register's outputs *and* the external input bits directly (matching $\lambda:S\times I\to O$'s signature).
- **General synchronous FSM architecture** — the fixed topology this note derives as correct: external input $\to$ next-state logic (together with state register's current output) $\to$ state register's $D$ inputs; state register's $Q$ outputs $\to$ fed back into next-state logic, and also into output logic (with external input additionally feeding output logic only in the Mealy case); one shared clock signal driving every flip-flop in the state register simultaneously.
- **Clock domain** — the set of flip-flops all driven by the same clock signal, updating at exactly the same edges; this note's architecture uses a single clock domain for the entire state register (multiple-clock-domain designs exist in general digital design but are out of this note's and this course's scope at this point).

## Intuition

**A flip-flop's $D$ input doesn't care whether it's wired to a raw external signal or to the output of a combinational circuit — Topic 10's proof never assumed one or the other.** Topic 10, Section 2 proved $Q^+=D$ holds at every rising edge regardless of *what* $D$ is, as long as $D$'s value is well-defined at the edge; Topic 10's own Self-check Question 8 already pushed this further, proving that even when $D$ is itself derived from *another* flip-flop's output (chaining two flip-flops on the same clock), the capture is still race-free, because each flip-flop's data input is provably constant throughout the entire half-cycle preceding the edge it needs to be stable for. Topic 12's next-state logic is exactly this same situation, just with possibly-many state bits and an external input feeding into a combinational function instead of a bare wire — nothing about the underlying correctness argument changes in kind, only in how many signals are being tracked at once.

**An FSM's feedback loop is the SR latch's feedback loop, tamed.** Topic 08's cross-coupled gates fed a gate's output directly back into another gate's input with no clock in between — which is precisely why that circuit needed careful self-consistency-equation analysis to even determine whether a stable solution existed (and, at $S=R=1$, it famously didn't, in the well-defined sense Topic 08 required). An FSM's state register output *also* feeds back into logic that determines its own next value — the same fundamental "output influences its own future input" shape — but the flip-flop's edge-triggering (Topic 09, Topic 10) breaks that loop into two cleanly separated phases: computing the *next* value (combinationally, freely, throughout the cycle) and *committing* to it (atomically, only at the edge). There is no analog here of Topic 08's "does a solution exist" question, because the next-state logic is an ordinary combinational circuit (Topics 03–07), which — unlike a bare cross-coupled gate loop — is guaranteed by its very construction (a DAG of gates, no combinational cycles) to have exactly one well-defined output for any given input.

**The Moore/Mealy wiring difference is not just notation — it's a genuine, physically enforced difference in which wires exist.** Topic 11 defined Moore and Mealy by the *signature* of $\lambda$; this note makes that a literal, physical fact about the circuit: a Moore FSM's output logic block simply has no wire carrying the external input into it at all, so it is *structurally impossible* for the output to depend on the current input, no matter what gates are used inside that block. A Mealy FSM's output logic does have that wire, making same-cycle input-dependence possible (though not mandatory — Topic 11 Section 4's Moore-to-Mealy conversion showed a Mealy output function that simply ignores the input is a valid, if wasteful, special case).

## Derivation / formalism

### 1. The general architecture, and why next-state logic is a direct application of Topic 12's equations

Given Topic 12's next-state equations $D_i=Q_i^+=f_i(Q_{k-1},\dots,Q_0,x_1,\dots,x_m)$ for $i=0,\dots,k-1$: build one combinational circuit per $f_i$ using Topics 03–04's gate-realization techniques (any of these equations is an ordinary Boolean expression over $k+m$ variables, exactly the kind of expression Topics 03–04 already showed how to realize as a gate network), with inputs $Q_{k-1},\dots,Q_0$ (wired from the state register's own outputs) and $x_1,\dots,x_m$ (wired from the FSM's external input pins). Connect each such circuit's output directly to the corresponding flip-flop's $D$ input. This is a direct, mechanical realization — no new derivation is needed here beyond citing Topics 03–04 (any Boolean expression can be built as a gate network) and Topic 12 (this is exactly which expression to build).

### 2. Correctness: the whole state register updates atomically and correctly at every clock edge

**Claim:** at every rising edge of the shared clock, the state register's new value $(Q_{k-1}^+,\dots,Q_0^+)$ equals $(f_{k-1}(Q,x),\dots,f_0(Q,x))$ evaluated using the state and input values that held throughout the *entire* clock cycle immediately preceding that edge — with no dependence on any flip-flop's *new*, post-edge value, and no race between flip-flops.

**Proof, generalizing Topic 10 Self-check Question 8's two-flip-flop argument to $k$ flip-flops.** Fix attention on the clock's low phase immediately preceding some rising edge (the argument is identical, relabeled, for the high phase preceding a negative-edge design — Topic 10, Section 3). Throughout that entire low phase, by Topic 10 Section 2's first case ("$\text{CLK}$ stays at $0$"), *every* flip-flop $i$ in the state register has a constant output $Q_i$ — none of them are changing, because none of them are at a triggering edge during this stretch. Since the external input $x_1,\dots,x_m$ is, by the synchronous-FSM assumption (Topic 11, Section 2), also read as a fixed value for the purposes of this cycle's transition, every input to every next-state logic block $f_i$ is therefore constant throughout this entire preceding interval. A combinational circuit (Topics 03–07) is, by construction, a memoryless function of its *current* inputs only — feeding it constant inputs for an entire interval produces a constant output for that same interval (this is simply the definition of "combinational," restated: no combinational circuit built in this course has any way to produce a time-varying output from time-invariant inputs). So each $D_i=f_i(Q,x)$ is *also* constant throughout the entire preceding low phase — settled to its final value well before the edge is reached, not merely "at" the edge in some infinitesimal sense.

At the rising edge itself, each flip-flop $i$ captures $D_i$'s value "at the edge" (Topic 10, Section 2, third case) — but by the constancy just established, this is simply $D_i$'s single, already-settled value from throughout the preceding interval, i.e. $f_i$ evaluated at the *old* (pre-edge) state and input values. Crucially, this holds *simultaneously and independently* for every flip-flop $i=0,\dots,k-1$: none of them is waiting on any *other* flip-flop's new value, because every $D_i$ was already fully determined before any flip-flop had changed at all. This is exactly Topic 10 Self-check Question 8's zero-delay argument (there applied to $D_2=Q_1$, a single dependency between two flip-flops), generalized to $k$ flip-flops whose $D_i$'s may each depend on *all* of $Q_{k-1},\dots,Q_0$ simultaneously — the argument goes through identically because it never actually depended on how many flip-flops or how complex the combinational dependency was, only on the fact that every $Q_i$ was provably constant throughout the whole preceding interval. So the entire state vector updates atomically, in one step, to $(f_{k-1}(Q,x),\dots,f_0(Q,x))$, which by Topic 12's construction equals $\text{code}(\delta(s,x))$ for the FSM's actual next state — matching the target FSM's behavior exactly. $\blacksquare$

### 3. Output logic wiring, and the physical enforcement of Moore/Mealy timing

For a Moore FSM, build the output logic from Topic 12's output equations, which (per Topic 12's Core definitions) are functions of $Q_{k-1},\dots,Q_0$ only — wire only the state register's outputs into this block, with no wire at all carrying $x_1,\dots,x_m$ into it. Since the block has no input pins for the external input in the first place, its output *cannot* depend on the current input under any circumstance — this is Topic 11 Section 2's Moore timing property (output reflects only the state established through the *previous* cycle's transition), now guaranteed by the physical absence of a wire, not merely by a promise about which equation was used.

For a Mealy FSM, build the output logic from Topic 12's output equations (which may depend on both state and input bits), wiring in both the state register's outputs *and* the external input directly — since this block is an ordinary combinational circuit reading its current inputs (Topics 03–07), its output reflects the current cycle's input immediately, with no clock-edge delay, matching Topic 11 Section 2's Mealy timing property.

### 4. Contrast with Topic 08's unclocked feedback: why no self-consistency puzzle arises here

Topic 08's cross-coupled gates required solving equations like $Q=\overline{R+\overline Q}$ for self-consistent fixed points, because the feedback path had no clock breaking it into phases — the same instant's $Q$ appeared on both sides of the equation, and Topic 08 had to separately verify a solution existed (and was unique, except at the forbidden input) by direct substitution. In this note's architecture, the feedback path is: state register output $\to$ next-state logic $\to$ flip-flop $D$ input $\to$ (only at the *next* edge) new state register output. The next-state logic itself is guaranteed acyclic (Topics 03–04's gates are combined into finite networks with no feedback internally — a gate's own output is never wired back into its own input within the next-state logic block itself), so it always has a well-defined output for any input, by the ordinary evaluation procedure of Topics 03–07 — there is no "does a solution exist" question to ask, unlike Topic 08's bare cross-coupled loop. The flip-flop is precisely what converts "circuit computes its own future input" (a potentially ill-posed simultaneous system, Topic 08's territory) into "circuit computes its own future input, but that computation is read only once and then frozen until the next edge" (a well-posed, one-step-at-a-time recurrence, this note's territory) — Section 2's proof is exactly the formal version of this claim.

## Worked examples

### Example 1 — Full circuit for Topic 11/12's 2-state Mealy "detect two consecutive 1s" machine

From Topic 12, Example 1: $D=Q^+=x$, $Z=Qx$ (1 state bit, Mealy).

**Circuit:** state register $=$ 1 D flip-flop, output $Q$. Next-state logic: since $D=x$ has no dependence on $Q$ at all, the "combinational circuit" computing it is trivial — a direct wire from the external input $x$ to the flip-flop's $D$ pin (a degenerate but entirely valid instance of Section 1's next-state logic, needing zero gates). Output logic (Mealy, Section 3): one 2-input AND gate (Topic 04) computing $Z=Qx$, with inputs wired to the flip-flop's $Q$ output *and* directly to the external input $x$ — demonstrating the Mealy output logic's defining feature, a wire carrying $x$ straight into the output block.

**Trace, input $1,1,0,1,1,1$, starting $Q=0$ (verifying Section 2's atomic-update claim on real numbers, matching Topic 11 Example 1's trace exactly since these are the identical equations):**

| Cycle | $Q$ (before edge) | $x$ | $D=x$ | $Z=Qx$ | $Q$ (after edge, $=D$) |
|---|---|---|---|---|---|
| 1 | 0 | 1 | 1 | 0 | 1 |
| 2 | 1 | 1 | 1 | 1 | 1 |
| 3 | 1 | 0 | 0 | 0 | 0 |
| 4 | 0 | 1 | 1 | 0 | 1 |
| 5 | 1 | 1 | 1 | 1 | 1 |
| 6 | 1 | 1 | 1 | 1 | 1 |

$Z$ sequence: $0,1,0,0,1,1$ — matches Topic 11 Example 1's Mealy output trace exactly, confirming the circuit (not just the abstract equations) reproduces the specified FSM behavior.

### Example 2 — Full circuit for Topic 11/12's 3-state Moore machine

From Topic 12, Example 2: $D_1=Q_1^+=Q_0x$, $D_0=Q_0^+=x$, $Z=Q_1$ (2 state bits, Moore).

**Circuit:** state register $=$ 2 D flip-flops, outputs $Q_1,Q_0$. Next-state logic: one 2-input AND gate computing $D_1=Q_0x$ (inputs: flip-flop 0's output $Q_0$, and external input $x$ — note $D_1$ depends on the *other* flip-flop's output, $Q_0$, not its own, $Q_1$, a direct instance of Section 2's "each $D_i$ may depend on all state bits simultaneously"); a direct wire from $x$ to $D_0$ (since $D_0=x$ needs no gate, same degenerate case as Example 1). Output logic (Moore, Section 3): a direct wire from the flip-flop 1's output $Q_1$ to the output pin $Z$ — critically, **no wire at all** connects the external input $x$ to the output logic, physically enforcing the Moore timing guarantee.

**Trace, input $1,1,0,1,1,1$, starting $(Q_1,Q_0)=(0,0)$:**

| Cycle | $(Q_1,Q_0)$ before edge | $x$ | $D_1=Q_0x$ | $D_0=x$ | $Z=Q_1$ (this cycle, using *pre*-edge $Q_1$) | $(Q_1,Q_0)$ after edge |
|---|---|---|---|---|---|---|
| 1 | $(0,0)$ | 1 | $0\cdot1=0$ | 1 | 0 | $(0,1)$ |
| 2 | $(0,1)$ | 1 | $1\cdot1=1$ | 1 | 0 | $(1,1)$ |
| 3 | $(1,1)$ | 0 | $1\cdot0=0$ | 0 | 1 | $(0,0)$ |
| 4 | $(0,0)$ | 1 | 0 | 1 | 0 | $(0,1)$ |
| 5 | $(0,1)$ | 1 | 1 | 1 | 0 | $(1,1)$ |
| 6 | $(1,1)$ | 1 | $1\cdot1=1$ | 1 | 1 | $(1,1)$ |

$Z$ sequence: $0,0,1,0,0,1$ — matches Topic 11 Example 2's (and Topic 12 Example 2's) Moore output trace exactly, and note $Z$ each cycle used only the *pre-edge* $Q_1$ (the state established by the *previous* cycle's transition), never that same cycle's input $x$ directly — a concrete demonstration that the Moore output logic's missing input wire is doing exactly the job Section 3 claims.

## Common pitfalls

- **Accidentally wiring the external input directly into a Moore FSM's output logic.** This silently converts the circuit's *actual* timing behavior to Mealy-style same-cycle input-dependence, even if the *equations* used were originally derived as Moore output equations — the physical wiring, not just the algebra, is what determines the real timing (Section 3); always check the output logic block's input pins match the intended flavor.
- **Giving different flip-flops in the state register different clock signals (or the same signal through different amounts of buffering/delay).** Section 2's atomicity proof depends critically on *every* flip-flop transitioning at the *same* edge, which is only guaranteed if they share one true clock domain (Core definitions); splitting the state register across clock domains reopens exactly the kind of race Topic 09's transparency problem and Topic 10's flip-flop were built to eliminate, now at the multi-flip-flop level.
- **Confusing next-state logic's inputs with output logic's inputs.** Next-state logic always taps *both* the state register's outputs and the external input (Section 1), regardless of Moore/Mealy — the Moore/Mealy distinction only affects *output* logic's inputs (Section 3); building next-state logic without wiring in the external input at all would make the FSM incapable of reacting to input in its transitions, an entirely different (and almost certainly wrong) design.
- **Worrying that the next-state logic's feedback loop needs Topic 08-style self-consistency-equation checking.** Section 4 explains why this concern doesn't apply here: the next-state logic is an acyclic combinational network (Topics 03–07), always has a unique well-defined output for a given input, and the flip-flop (not the combinational logic) is what mediates the actual "output feeds future input" loop, one clock edge at a time — there is no analog of Topic 08's forbidden-state or metastability concerns *within* the next-state logic itself.
- **Assuming next-state logic and output logic must always be physically separate gate networks with no shared circuitry.** This note builds them as conceptually distinct blocks for clarity, and nothing in the correctness proof (Section 2) forbids sharing sub-expressions between them in a real implementation (e.g. if some intermediate AND term is useful for both a next-state bit and an output bit) — that's a legitimate optimization, just one this note doesn't derive or require.
- **Treating a next-state logic block with no gates (Example 1 and Example 2's $D_0=x$ direct-wire case) as somehow "not really" next-state logic.** A direct wire is a valid (degenerate, zero-gate) combinational circuit — Section 1's construction never required at least one gate, only that $D_i$ be *some* combinational function of the state and input, and the identity function realized by a plain wire is a perfectly valid combinational function.

## Self-check

### Questions

1. (Easy) In the general architecture (Section 1), what are the two inputs to the next-state logic block?
2. (Easy) True or false: a Mealy FSM's output logic has a wire carrying the external input directly into it. Justify in one sentence.
3. (Medium) Using Example 2's circuit, verify the transition from $(Q_1,Q_0)=(0,1)$ with $x=1$ produces $D_1=1,D_0=1$, and state which next state this corresponds to.
4. (Medium) Explain, using Section 2's proof, why it does not matter that $D_1$ in Example 2 depends on $Q_0$ (a *different* flip-flop's output) rather than its own $Q_1$.
5. (Medium) A designer accidentally wires two of a 3-flip-flop state register's flip-flops to $\text{CLK}$ directly and the third to a separately-buffered copy of $\text{CLK}$ that arrives slightly later. Explain, citing Section 2, why this risks breaking the architecture's correctness guarantee even if the buffered copy is "almost" the same signal.
6. (Hard) Suppose a Mealy FSM's output equation is $Z=Q_1\bar x + Q_0x$ (depends on both state bits and the input). Using Section 3's wiring rules, describe which specific wires must be present in the output logic block, and explain what would go wrong (in terms of a missing input to a gate) if the $x$ wire into the output logic were omitted by mistake.
7. (Hard) Using Section 2's proof structure, explain what would go wrong (specifically, which step of the proof would fail) if a next-state logic block itself contained an internal feedback loop (e.g. one of its own gates' outputs wired back into an earlier gate's input within the *same* block, before reaching any flip-flop) — connect your answer to Topic 08's concerns.
8. (Hard) Prove that Example 1's degenerate ("wire, no gates") next-state logic is still correctly described by Section 2's atomicity proof — i.e., that the proof's argument ("each $D_i$ is constant throughout the preceding interval because it's a combinational function of constant inputs") applies even when the "combinational function" in question is just the identity function realized by a bare wire.

### Answers

1. The state register's current outputs $Q_{k-1},\dots,Q_0$ (fed back) and the FSM's external input bits $x_1,\dots,x_m$ (Section 1).
2. True. Per Section 3, a Mealy output equation may depend on both state and input (matching Topic 11's $\lambda:S\times I\to O$ signature), so its output logic block must have an actual wire carrying the external input in, or it would be physically incapable of computing such a dependence.
3. From Example 2's equations: $D_1=Q_0x=1\cdot1=1$. $D_0=x=1$. So $(D_1,D_0)=(1,1)$, meaning the state register captures $(Q_1,Q_0)=(1,1)$ at the next edge — this is the code word for state $B_1$ (per Topic 12 Example 2's encoding), matching the expected transition $B_0\xrightarrow{1}B_1$ from the original Topic 11 machine.
4. Section 2's proof establishes that *every* state bit $Q_i$ (not just $Q_1$ itself) is provably constant throughout the entire preceding clock phase, and that every next-state logic block's inputs — which may draw from *any* combination of state bits, not only the "matching" one — are therefore also constant throughout that same interval. The proof never singles out "a flip-flop's own previous value" as special; it treats the whole state vector as jointly constant, so $D_1$ depending on $Q_0$ instead of $Q_1$ is no different, structurally, from depending on $Q_1$ itself — both are already-settled, non-racing values by the time the edge arrives.
5. Section 2's proof requires every flip-flop to transition at the *same* edge, so that the state vector update is atomic and every other flip-flop's next-state logic is evaluated against a single, universally-agreed "current state." If one flip-flop's clock arrives measurably later, there is a window where two flip-flops disagree about whether the transition has happened yet — a next-state logic block reading the early-clocked flip-flops' *new* values while the late-clocked flip-flop still shows its *old* value would compute a $D$ based on a state vector that never actually existed as a coherent whole, breaking the "constant throughout the preceding interval" premise Section 2's proof depends on, even if the timing skew is small (this is, in fact, the seed of the concern Topic 15's clock skew note develops in full).
6. Per Section 3, the output logic block for this equation needs: two wires from the state register ($Q_1$ and $Q_0$), a wire carrying the external input $x$ directly in, an inverter (Topic 04) to produce $\bar x$, two AND gates (one computing $Q_1\bar x$, one computing $Q_0x$), and one OR gate combining them. If the $x$ wire into the output logic were omitted, neither AND gate could be built as specified — the gate computing $Q_1\bar x$ would be missing one of its two required inputs entirely, making the equation impossible to realize as written; the output logic would have to fall back to some function of $Q_1,Q_0$ alone, which cannot correctly reproduce a genuinely input-dependent Mealy output.
7. Section 2's proof relies on the next-state logic being an ordinary, acyclic combinational circuit — one whose output is a well-defined function of its current inputs, guaranteed by Topics 03–07's construction (no gate's output feeds back into an earlier gate's input within the same block). If a feedback loop existed *inside* the next-state logic itself, the "combinational circuit produces a constant output for constant inputs" step of Section 2's proof would no longer be automatically guaranteed — internally-fed-back gate networks are exactly Topic 08's territory (self-consistency equations, possibly multiple solutions or no solution at a forbidden combination), not Topics 03–07's guaranteed-single-valued combinational territory. The proof's premise (next-state logic behaves as an ordinary memoryless function) would need to be separately re-established using Topic 08-style analysis before Section 2's argument could even begin — the clean separation between "combinational logic, always well-defined" and "flip-flop, the only place feedback crosses a clock edge" that this note's whole architecture depends on would be violated.
8. The identity function $D=x$ (realized by a bare wire) is trivially a combinational function of $x$: it has no internal state, no memory, and its output at any instant is completely determined by its input at that same instant (in fact even more directly than a gate network, since there's no gate-delay to reason about at all — the wire's "output" simply *is* its input, by definition of what a wire does). Section 2's proof only used the property "combinational circuits produce constant output when fed constant input for an interval" — this holds for the identity function exactly as it holds for any other combinational function (AND, OR, or an arbitrarily deep gate network): feed $x$ held constant at some value throughout an interval, and the wire's output (which just *is* $x$) is, trivially, that same constant value throughout the same interval. So the proof's argument applies to Example 1's degenerate case with no modification — a direct wire is simply the smallest possible instance of "a combinational function of the current input," not an exception to Section 2's reasoning.

## Summary / cheat sheet

**Architecture:** state register ($k$ D flip-flops, one shared clock) $\leftrightarrow$ next-state logic (combinational, inputs $=$ state $+$ external input, outputs $=D_i=Q_i^+$) feeding back into the register; output logic (combinational, inputs $=$ state only for Moore, state $+$ input for Mealy).

**Correctness (Section 2):** every flip-flop's $D_i$ is a combinational function of state+input, both provably constant throughout the entire clock phase preceding an edge (Topic 10's "steady" case) — so every $D_i$ settles before the edge, and the whole state vector updates atomically with no inter-flip-flop race, directly generalizing Topic 10 Self-check Q8's two-flip-flop zero-delay argument to $k$ flip-flops.

**Moore vs. Mealy, physically:** Moore output logic has no wire for the external input at all (structurally enforces the one-cycle-delay property); Mealy output logic does (structurally enables same-cycle input-dependence).

**Contrast with Topic 08:** the flip-flop breaks "output feeds its own future input" into two clean phases (combinational computation, then atomic commit at the edge) — no self-consistency-equation puzzle, because next-state logic is always an acyclic, single-valued combinational circuit.
